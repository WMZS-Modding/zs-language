# ☕ JAVA
Java is a complex language that requires extensive use of `{}`, numerous variable initializations, and many function calls. While primarily popular in Minecraft Java Edition and not resembling a natural language, this ZS style was created to address Java's difficulties and limitations.

## Note
Due to the lack of applications to run ZS scripts in Java style and the unofficial nature of this implementation, it cannot be used directly to create Java mods unless translated to actual Java code.
