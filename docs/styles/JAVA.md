# ☕ JAVA
This is a difficult language. Unlike other programming languages, it requires a lot of `{}`, a lot of initialization variables, a lot of functions to trigger, etc. Although this language is only popular in Minecraft JAVA Edition and it is not nearly a natural language, I created this style for ZS because it is to solve the difficulties and limitations of JAVA.

## Note
However, due to the lack of an application to run scripts in JAVA style and this style being unofficial, it cannot be used to create JAVA mods (unless translating this style to JAVA).
