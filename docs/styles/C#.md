# ⭐ CSHARP
C# is used to create scripts for engines like Unity. This language served as inspiration for designing the ZS C# style.

## ✏ How to use
While ZS is a natural language, proper usage requires attention to detail. Here are guidelines for the C# style:
- Ensure correct spelling and syntax
- Use special symbols appropriately
- Use curly quotes (`‘’` and `“”`) instead of traditional straight quotes (`'` and `"`)
- Use only present simple tense

To write functional script logic, you must use nouns and verbs correctly.

**Note on `call` and `trigger` verbs:** Both invoke functions but have different purposes:
- `call`: invokes one or multiple functions. Example: `Call <destroy>`
- `trigger`: invokes one or multiple scripts. Example: `Trigger <destroy>`

This style mimics C# syntax but uses nouns and verbs for simpler, more natural code with only one `{}`. It is well-suited for Unity-like engines, though the limitation is that ZS scripts cannot run directly in those engines without conversion.
