# ⭐ CSHARP
It is a language used to create scripts for Engines like Unity. I use this language as inspiration to design the ZS style
## ✏ How to use
Although ZS is a natural language, it is not easy. Here are some notes when using this style:
- Absolutely do not write wrongly
- Use special symbols correctly
- Do not continue to use traditional `'` and `"`, use curly single and double quotes
- Only use the present simple tense

To write logic for the script to work, it is necessary to use nouns and verbs.

Note for `call` and `trigger` verbs: Both are call function, but they're different:
- `call`: call a or multiple function(s). Example: `Call <destroy>`
- `trigger`: call a or multiple script(s). Example: `Trigger <destroy>`

Because it is a style, ZS has a writing style like C#, the only difference is that it uses nouns and verbs and the syntax is easier to write, using only 1 `{}`. This style is very suitable for Engines like Unity, but the limitation is that this script cannot be run in that Engine.
